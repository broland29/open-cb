# OpenChessBoard
The objective of OpenCB is to provide a solution that makes chess easier for beginners, in an interactive and interesting way, enhancing classical chess gameplay. To achieve this, two functionalities are required: detecting the chessboard state and validating the players’ movements according to the rules of chess.

Version 1.0 together with the docs below represent my license thesis for the Technical University of Cluj-Napoca. Feel free to consult the documents, use the code (with proper credit), or contact me for further questions.
