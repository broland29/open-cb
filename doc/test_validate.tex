\section{Validation and Response Module}

This module can be and is supposed to be tested, since it is composed of small components, one depending on another. Discovering bugs by playing chess games is an option, however there is no guarantee that this results in correctness, and it is not automated. For testing VAR, I used Google Test (GTest). There is a separate executable for testing only, so this can be built only when needed. A list of tests of \t{Attack} functions can be found below:
